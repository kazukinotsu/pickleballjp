🛰️ Target 早期検知 カレンダー未登録の新SKU＝未告知ドロップの可能性

「🔎 Target 早期検知スキャン」を押すと、いま Target の商品DBに載っている Squishmallow を取得し、カレンダーに無いものを新候補として表示します。

「事前に分かる」仕組み：小売の商品DBには一般販売前に SKU と発売日(street date)が登録されます。 Target はその情報を Redsky API で露出するため、棚に並ぶ前・購入可能になる前に検知できます。 Walmart / Walgreens は現状カレンダー管理（手動/コミュニティ更新）です。

サンプル行は構造を示すダミーで、実在の発売日ではありません。drops-data.json を実データに差し替えてください。
