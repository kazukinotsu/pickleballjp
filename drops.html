🛰️ Target 早期検知 未告知SKU＝これからドロップの可能性。発売日順に表示

ページを開くと Squeezy・NeeDoh・Smushmart・Smusher・RMS Dumplings の5ブランドを Target の商品DBから自動で一括取得し、カレンダーに無いものを「これからのドロップ候補」として発売日順に表示します（「🔎 Target 早期検知スキャン」で再取得）。

「事前に分かる」仕組み：小売の商品DBには一般販売前に SKU と発売日(street date)が登録されます。 Target はその情報を Redsky API で露出するため、棚に並ぶ前・購入可能になる前に検知できます。 ZIP を入れると最寄り店舗基準で判定します。Walmart / Walgreens は現状カレンダー管理（手動/コミュニティ更新）です。

サンプル行は構造を示すダミーで、実在の発売日ではありません。drops-data.json を実データに差し替えてください。
